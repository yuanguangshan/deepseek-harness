# One sentence → hand-drawn illustrated card v2 (an all-free AI pipeline)

English | [中文](README.zh.md)

Research conclusion: **no paid APIs needed — free endpoints already available on this machine/LAN + free image APIs + local Pillow layout are enough to auto-generate a hand-drawn-style illustrated card from one sentence.** The pipeline runs end to end and has produced finished cards (see `card_*.png`, preview in `preview.html`).

## Pipeline (3 steps)

```
一句话描述
  │  ① 文案扩展（免费 LLM）
  ▼
{title, body, quote, img_prompt, style(情绪风格)}
  │  ② 手绘图片生成（免费图片 API）
  ▼
PNG 插画
  │  ③ 排版合成（本地 Pillow，免费）
  ▼
手绘风图文卡片（情绪调色板 + 水彩晕染底 + 金句引语栏 + 圆角插画 + 印章落款）
```

## v2 improvements (2026-08-16)

1. **Emotion-driven palette**: the LLM additionally outputs a `style` field (warm/fresh/calm/night/autumn/spring/rain), and Pillow picks colors from 7 hand-drawn palettes by emotion, keeping title, body, border, and seal coordinated.
2. **Quote bar**: the LLM additionally outputs one apt `quote`, rendered above the body as a quote card with a left rule.
3. **Title ornament**: a short accent line + dots added under the title.

### v2.1 fix (2026-08-16)

The title ornament used to be laid out inside the title line (`dec_y = t_y + 26`); with a single-line title it crossed the middle of the glyphs like a strikethrough. It is now placed 16px below the actual bottom edge (`textbbox`) of the last line of glyphs, no longer overlapping the text.
4. **`--format long`**: 1080×1920 portrait long image (Xiaohongshu long-post style), smaller illustration, more spacious body.
5. **`--batch` bulk generation**: reads a multi-line description file and produces one card per line into the output directory.
6. **WeChat delivery**: finished cards can be uploaded to R2 (`rclone copyto <card> r2:yuangs/handdrawn/`, public URL `https://pic.want.biz/handdrawn/<card>`) → pushed to WeChat with the `wechat-send` skill.

- Alternative: machine u has Puppeteer (HTML+CSS → screenshot); this machine's Chrome headless is unavailable under the sandbox, so it was not used.

## Reproduce

```bash
cd /Users/ygs/ygs/deepseek-harness/handdrawn
# 安装依赖（仅首次，装到工作区不污染系统）
python3 -m pip install --target ./pylibs pillow -i https://pypi.tuna.tsinghua.edu.cn/simple

# 跑流水线（--engine 可选 sensenova / agnes）
PYTHONPATH=./pylibs python3 pipeline.py "春分时节，万物复苏" -o out.png --engine sensenova

# 竖版长图
PYTHONPATH=./pylibs python3 pipeline.py "一句话" --format long -o long.png

# 批量（lines.txt 每行一句）
PYTHONPATH=./pylibs python3 pipeline.py --batch lines.txt -o batch_out/
```

## Key findings

1. **Machine u (192.168.31.213) is the free AI resource hub**: its weclaw config carries 30+ free model endpoints (DeepSeek, GLM, Gemini, NVIDIA, OpenRouter, aiproxy, etc.), plus two image-generation scripts (`sensenova-img.py`, `agnes_image_gen.py`; keys are plainly available in the scripts and weclaw config).
2. **This mac is itself the proxy**: 8081 (Qwen), 8082 (chatgpt), and 8080 are all running, directly usable at zero cost.
3. **The image APIs are OpenAI-compatible `images/generations`**: callable in 3 lines from any language; no quota display, but continuous image generation worked in testing.
4. Layout depends on no online service — everything is done with local Pillow, and the style is freely customizable.

## Possible improvements

- Wire in machine u's Puppeteer for HTML/CSS layout for more refined typesetting (arbitrary fonts, gradients, decorative SVG).
- Add multi-image collage / nine-grid layouts.
- Bulk generation is supported (`--batch`); multi-engine auto-switching could be added (fall through to the next engine on failure).
- WeChat delivery works end to end (R2 + the wechat-send skill); it could become the pipeline's automatic final stage.
