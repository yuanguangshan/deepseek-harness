## 二、3081 看不到输入框的根因（已定位+已修复）

### 报错
`Error: cannot get property "remote.session" without inject` @ `directoryFor (service.ts:78)` ← `useSeatModelName (apply.ts:323)` ← `InputBar`，slot `conversation.composer.bar` 整体崩溃 → 输入框消失。

### 根因链条
1. `useSeatModelName`（composer 占位符实时显示模型名）是 **fork 自加功能**（commit `965053cc30`），上游没有——所以 **3080 官方包不会崩**（同一段 `directoryFor` 代码在官方包里也存在，但上游没人从渲染路径调它）。
2. 该 hook 在 React 渲染期跨包调用 ui-model-selection 的 `directoryFor()`。
3. cordis 的 caller-ctx tracker：服务方法里访问 `ctx.remote.session` 这类注入属性时，按**调用方**的 inject 环境校验；渲染路径没有 inject 环境 → cordis（`vendor/cordis/src/reflect.ts:144`）抛 `without inject`。
4. dev 分支合并时把 fork 特性和上游新代码组合，暴露了这个隐患。

### 修复（当晚另一会话已落地在 dev 工作区，已验证）
- `packages/client/ui-model-selection/src/client/service.ts`：构造函数里捕获 `this.sessionRemote = ctx.remote.session`（构造时处于自身 inject 环境，访问合法），`directoryFor` 改用 `this.sessionRemote`。
- 配套回归测试：`tests/browser-plugin.client.spec.ts` 用真 `Service` double 复现 caller-ctx 场景（14 用例全过，2026-09-08 23:25 实测）。
- lib 已重建（23:19），dev 工作区遗留两个未提交文件（service.ts + spec），**待提交**。
