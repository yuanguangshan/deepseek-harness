## 四、冲突与解决（8 处）

| # | 文件 | 冲突性质 | 解决 |
|---|---|---|---|
| 1 | `.gitattributes` | 两边各加一段规则 | 取并集：`*.patch -whitespace` + persistence-schema `linguist-generated` |
| 2 | `scripts/gen-tool-catalog.ts` | 两边各加 import | 取并集：fork 的 `ToolCompanion`/`Wechat` + 上游 `McpResources` |
| 3 | `tsconfig.base.json` | 生成区段（fork `memory` vs 上游 `mcp-resources`） | 取上游版后 `pnpm run gen-tsconfig-paths` 重生成；**另补 2 条手写别名**（见下） |
| 4 | `vitest.config.ts` | 两边各加测试条目 | 取并集：`workflow-ptc` + `apps/repl/*` |
| 5 | `packages/sdk/server/src/server.ts` | fork 的 provider 注册竞态等待 vs 上游 plugin 调用签名 | 保留 fork `waitForProvider` 逻辑，采用上游 `ctx.plugin(LlmDeepSeek)`（去掉 `{}`） |
| 6 | `packages/llm/llm-deepseek/src/adapter.ts` | 上游把单文件拆成 `protocols/{chat-completions,messages}` + `common/`，fork 的 `x-chat-id` 注入在原单体文件里 | 取上游新版委托层，fork 特性**抽成 `common/proxy-chat.ts`** 并接入两个协议适配器（见下） |
| 7 | `packages/client/ui-conversation/tests/input-bar.client.spec.tsx` | 上游把 `permissions` projection 改为 `permissionEntry` 插槽并大改结构 | 以上游重构版为基座，重放 fork 的 `modelSelection`/`seatModelName` 用例与 bench 选项 |
| 8 | `pnpm-lock.yaml` | 依赖图变动 | `pnpm install --no-frozen-lockfile` 重建 |

### 4.1 手写别名（生成器不覆盖）

上游新增的 `gen-tsconfig-paths` 要求「包名 ≠ 目录名」的包必须手写别名，否则 gate 直接失败。fork 的 sysadmin 两个包正属此类：

```jsonc
"@deepseek-ai/dsh-client-ui-settings-sysadmin": ["./packages/client/ui-settings-sysadmin/src"],
"@deepseek-ai/dsh-host-sysadmin": ["./packages/host/sysadmin/src"],
```

> 注：合并前 fork 的 `tsconfig.base.json` 里本就没有这两条（当时生成器未跑通），本次一并补齐，`gen-tsconfig-paths --check` 现已通过。

### 4.2 fork 的 x-chat-id 特性移植

原 fork 在单体 `adapter.ts` 的 `request()` 里注入本地 proxy 会话保持头：

```
x-chat-id:    sessionId（session-title 用途固定为 dsh-title-gen 共享命名空间）
x-chat-reset: 1（仅 compaction —— 压缩即重写上下文，必须让 proxy 重开上游）
```

上游重构后请求构造分裂到两个协议适配器，故抽成零依赖纯函数 `common/proxy-chat.ts:proxyChatHeaders(options)`，在 `protocols/chat-completions/adapter.ts` 与 `protocols/messages/adapter.ts` 各展开一次。相比原内联写法，**与上游文件的重叠面从「大段逻辑」缩到「一行展开」**，后续再合上游时冲突成本更低。

### 6.3 网络坑：`@trycua/cua-driver-darwin-arm64` 下载超时

上游新增实验包 `packages/experimental/computer-use-cua-driver-native` 依赖 `@trycua/cua-driver@0.28.0`，其 darwin-arm64 二进制 **18MB**，从 `registry.npmjs.org` 下载在 pnpm 默认 fetch 超时（60s）内完不成，连续两次 `ERR_PNPM_BROKEN_METADATA_JSON`。

处置：改用镜像源 + 放大超时（锁文件只存 integrity 不存 registry URL，切源不污染锁文件）：

```bash
pnpm install --no-frozen-lockfile \
  --registry=https://registry.npmmirror.com \
  --fetch-timeout 1800000 --fetch-retries 5
```

### 6.4 全局 npm

npm 11 默认拦截安装脚本，需显式放行（否则 koffi/node-pty 原生模块不编译）：

```bash
npm install -g --registry=https://registry.npmmirror.com \
  --allow-scripts=@deepseek-ai/dsh-subprocess-local,koffi,node-pty,@google/genai,protobufjs \
  @deepseek-ai/dsh@0.1.6-alpha.1
```
